REx v0.5 model assets are deliberately not bundled in SOURCE ZIP.
GitHub Gradle build downloads and embeds 3 official ZIP assets in APK:
1. vosk-model-small-cn-0.22.zip (Mandarin)
2. vosk-model-small-en-us-0.15.zip (English)
3. vosk-model-spk-0.4.zip (speaker embeddings)
Do NOT install source ZIP as APK. Genuine Android build required.
No ColorOS speech engine or network needed on phone for recognition.
Speaker embeddings are experimental and lack anti-spoof verification.
