# REx Android v0.2 · 粒子与语音唤醒联调版

适配目标：一加 Ace 3V / PJF110、Android 16 / ColorOS 16.0.5。

**这是完整的 Android 工程，不是 APK。** 可在 GitHub Actions 生成调试版 APK，电脑无需 Android Studio。代码在本地做了语法、指令映射和静态检查，但当前执行环境没有 Android SDK，所以未能生成或验证可安装 APK。

## 本版相较 v0.1 已改

1. **重新绘制 REx 粒子**：1940 个更细的红色粒子按 97 组丝状结构分布，背景为暗色科幻网格；**彻底移除中心白色/蓝色发光核以及三层圆环**。
2. **待机模式**：粒子半径为唤醒状态的 **70%**，聚拢且不进行周期性旋转。**唤醒状态**：粒子放大、散开、慢速流动；识别器报告说话时呈现强烈的局部扭曲与波动。
3. **唤醒词**：`Rex`、`Rex醒了吗`，增加中文语音识别常见转写 `瑞克斯`、`雷克斯`。独立指令在唤醒后的 12 秒内有效；也支持一句话 `Rex，前进`。**仅显示识别，不授权红外运动**。
4. **重新处理 ColorOS 识别器**：优先尝试手机本机离线识别器。若不可用，明确提示并在**你允许**之后使用系统默认识别服务。后者可能使用网络；即使请求离线识别，服务端也可能忽略。
5. **改进句尾与重试**： `onBeginningOfSpeech` 表示识别器开始报告人声，`onEndOfSpeech` 表示识别器检测到句尾；**最终命令只在 `onResults`** 处理。请求语音停止后约 650～850ms 的静音分句，但 Android 实现可能忽略这些参数。安静环境中 `NO_MATCH` / `SPEECH_TIMEOUT` 不再指数增加重试间隔，异常实时显示。
6. **显示故障状态**：识别器缺失、中文语音模型缺失、麦克风权限不足、服务占用、网络失败会直接显示在 REx 界面。
7. **模式切换**：左下角空白处连续三击切换按键；按键界面收到识别后的唤醒词立即回到智能体界面（应用仍在前台时）。按键模式有语音启动/长按关闭入口，允许后台运行的麦克风前台服务。
8. **保持原有按键命令和 NEC**：按键发送一次 38kHz / NEC extended 0x3B4C + 命令字节，没有修改之前的指令映射；这是手机发射端，不代表 NanoPC 已收到或执行。
9. 不修改 `/srv/rex/rex_ws`，不接入机器人电机。

## 必须明确的限制

- **尚不能证明“只听本人声音”**：Android `SpeechRecognizer` 是语音转文字服务，没有可靠的主人的声纹验证或防录音重放能力；VAD 也不能保证过滤掉歌曲里的人声/电视说话。为避免误控制实机，本版语音解析**不发送 IR 运动命令**，只在屏幕显示和切模式。正式语音控制需要经过设备验证的声纹/唤醒模型与独立机器人安全保护。
- 安卓默认 `SpeechRecognizer` **不是保证可在任何手机全天无间断运行的唤醒引擎**。本版在前台启动后使用麦克风前台服务，可能在后台继续听，但会受到 ColorOS 电源管理、识别服务、权限等限制；如果用户强制结束 App，不能继续运行。
- 如果手机不提供独立离线语音服务，可选择系统默认识别，**它可能联网**；有明确弹窗供你选择。要禁止任何可能联网的语音，请不要授权系统识别。
- NanoPC 6.1.141 当前看不到 `/dev/lirc*` 或 `/sys/class/rc/*`，板载 IR 接收设备尚未启用。**本版不驱动机器人运动。**
- 在红外单向链路中，“停止”可能丢失，因此不能把“持续走直到停”作为没有独立安全措施的实机安全行为。

## 手机上怎么操作

1. 安装并打开 `app-debug.apk`，默认出现静止、缩小的红色 REx 粒子团。
2. 点击下方「开启语音监听」，允许麦克风。若提示离线识别引擎不存在，可以在弹窗选择允许系统识别（可能联网）。
3. 注意识别状态：`正在听` → `检测到人声` → `句尾已检测` → `识别完成`。说「Rex」或「瑞克斯」；**只有最终识别出唤醒词才展开粒子**。
4. 唤醒后说「前进」「停」等，屏幕显示识别指令及“未发射红外”，显示声音波动。也可以说「Rex，前进」。
5. 屏幕左下角空白处三击进入按键；在按键模式下说「Rex」可自动回到粒子界面。按键仍可尝试发送一次 NEC 红外帧，用于发射端联调。
6. 按住「语音监听」超过 1.1 秒可关闭前台麦克风服务；点击可重新请求启动。

## 无需 Android Studio 的 APK 生成

将本 ZIP **解压后全部文件**更新到现有 GitHub 仓库对应路径，保留目录结构；`.github` 在有些上传界面隐藏，如果网页无法拖入，可以直接在仓库里编辑 `.github/workflows/build-apk.yml`，内容与 ZIP 对应文件一致。点击 GitHub **Actions → REx Android v0.2 APK → Run workflow**。成功后在页面底部 Artifacts 下载 `REX-v0.2-debug-APK`，解压得到 `app-debug.apk`，在一加 Ace 3V 上安装。

**安装升级注意：** GitHub Actions 每次不同 runner 的调试签名可能不同；如果提示签名不匹配，需要先卸载旧的 REx 应用（用户数据会丢失）再安装新的调试 APK。正式发布应使用固定的私有签名证书。

本工程结构：`app/`（手机代码）、`.github/workflows/build-apk.yml`（云端构建）、`nanopc/`（旧 IR 只读检测和帧资料）、`docs/`（联调安全说明）、`tests/`（Java 本地指令测试）。
